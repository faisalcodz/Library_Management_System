\# Library Management System



\## Project Description



A CLI based Library Management System built using Python and MySQL.



\## Features



\- Add new book

\- Remove book

\- Update book information

\- Search books

\- Issue books

\- Return books

\- View all books

\- View issued books

\- File logging

\- Exception handling





\## Technologies Used



\- Python

\- MySQL

\- Git

\- OOP Concepts





\## Database Setup



Create database:



library\_management\_project





Tables:



\- books

\- users

\- issued\_books





\## Run Project



Install requirements:



pip install -r requirements.txt





Run:



python main.py
